# مولّد اللوحات السعودية ثلاثية الأبعاد

أداةٌ في المتصفّح تحوّل نصّاً إلى **ملفِّ طباعةٍ ثلاثيِّ الأبعاد** للوحة
سيارةٍ سعودية — تُفتح ويُكتب فيها ويُنزَّل الملفّ، بلا تسجيلٍ ولا رفعِ
شيءٍ إلى خادم.

**<https://relifeg1.github.io/ksa-plate3d/>**

## ما تفعله

- **ثلاثةُ تخطيطات**: عادية ٣٣٥×١٥٥، طويلة ٥٢٠×١١٠، رياضية ٣١٠×١١٠ — مقاساتٌ
  مقيسةٌ من لوحاتٍ حقيقية.
- **صفّان مستقلّان**: تختار أيُّهما عربيٌّ وأيُّهما لاتينيّ، وأرقامَ كلِّ
  صفٍّ على حدة، أو تُسقط صفّاً كاملاً.
- **نصٌّ عربيٌّ متّصل** إن أردت كلمةً لا حروفاً مقطّعة — بأشكال الوصل
  الأربعة ولام-ألف.
- **التصدير**: `3MF` ملوَّنٌ بأربعة أجزاء لطابعات الألوان، أو `STL` واحدٌ
  أو مقسَّمٌ بالألوان، أو `SVG` لوجه اللوحة.
- **الملحقات**: ثقوبُ براغٍ، مغانطُ، حلقةُ مفاتيح، تعليقُ جدار، نقشٌ غائرٌ
  بدل البارز.
- **حارسُ الطباعة**: يقيس أنحفَ تفصيلٍ في المجسَّم ويُنبّه إن نزل عن قطر
  الفوهة قبل أن تُهدر مادّةً ووقتاً.

## التشغيل محلّياً

لا بناءَ ولا تبعيات. أيُّ خادمٍ ساكن:

```bash
python -m http.server 8000
```

ثمّ `http://localhost:8000`. ولا يعمل بفتح `index.html` مباشرةً من القرص،
لأنّ المتصفّح يمنع تحميلَ الملفّات المجاورة من `file://`.

## ما بداخلها

| | |
|---|---|
| `src/layout.js` | المحرّك: يبني وجهَ اللوحة كنتوراتٍ بالمليمتر |
| `src/geometry.js` | البثقُ إلى مجسَّمٍ مغلق |
| `src/exporters.js` | STL و3MF وSVG |
| `src/glyphs.js` | الرموزُ مساراتٍ مطبَّعةً على `em = 1` |
| `vendor/` | three.js وحدَها — لا شيءَ يُحمَّل من الإنترنت |
